# 出力
- ファイル名: `scan.md`
- 出力先: 入力画像が置かれているディレクトリ(複数ディレクトリにまたがる場合は、最初に指定された画像のディレクトリ)。
- 入力ファイルが複数の場合でも、出力はひとつのファイルにまとめる。
- 既存の `scan.md` がある場合は、既存の内容を残したまま末尾に追記する。
- 同一の入力ファイル名(P.ページ番号)のセクションが既に存在する場合は、再スキャンとみなし該当セクションを上書きする(重複追記しない)。

# 処理順序
- 複数画像は、抽出できたページ番号の昇順で処理・出力する。
- ページ番号が「不明」の画像は、末尾にまとめて入力順に出力する。

# 行うこと
与えられた画像の集合を入力として、それぞれについて下記を行う。

1. **ページ番号の抽出**
   - 画像内の数字(ノンブル)からページ番号を抽出する。
   - 抽出できなかった場合は「不明」とする。

2. **テキストの抽出**
   - 画像からテキストを抽出する。
   - 黄色または赤色の枠が1つ以上ある場合、抽出範囲はその枠内のみに限定する。枠が複数ある場合は、画像内での上から下・左から右の順にすべて抽出し、枠ごとに空行で区切る。
   - 上記以外の色の枠は無視する。
   - 縦書き・横書きに関わらず、自然な読み順(縦書きなら右から左)でテキストを整形する。
   - 判読不能な文字は `[判読不能]` と記す。

3. **出力への追加**
   - `scan.md` に以下形式のセクションとして追加する。

     ```markdown
     ## {入力ファイル名} (P.{ページ番号})

     {抽出したテキスト}
     ```

   - ページ番号が不明な場合: `## {入力ファイル名} (P.不明)`

# エラー時の扱い
- 画像が読み込めない、または破損している場合は、その旨をセクション内に `[画像を読み込めませんでした]` として記録し、処理を継続する。
- テキストが一切検出できない場合は、本文を空欄にせず `[テキストなし]` と記す。
